SELECT
  COALESCE(status, 'UNKNOWN') AS loan_status,
  COUNT(*) AS total_loans,
  ROUND(AVG(credit_score), 0) AS avg_credit_score,
  ROUND(SUM(ead), 2) AS total_ead,
  ROUND(AVG(pd_est) * 100, 2) AS avg_pd_pct,
  ROUND(SUM(expected_loss), 2) AS total_expected_loss,
  ROUND(SUM(net_risk_adjusted_revenue), 2) AS net_risk_adj_revenue
FROM workspace.loan_risk_dev.gold_portfolio_risk
GROUP BY status
ORDER BY total_expected_loss DESC;

Clinical & Lab Lakehouse with Automated PHI De-Identification

Medallion + Privacy Gate

Designed for messy, multi-source clinical encounters and laboratory exports. Automates salted pseudonymous key generation, regex scrubbing of free-text clinical notes, strict unit/range validation with quarantine logging, and curated longitudinal patient feature marts for ML training.

PySpark Delta Lake PII/PHI Hashing & Redaction Data Quality Quarantine SQL Lineage Audit
  • Deterministic Pseudonymization: Converts direct patient identifiers into salted SHA-256 subject_key tokens so longitudinal lab joins work without exposing raw PII/PHI.
  • Clinical Note Redaction: Strips phone numbers, email addresses, and ID patterns from unstructured clinical notes prior to Silver persistence.
  • ML-Ready Gold Features: Delivers normalized lab indicators, abnormal-flag counts, missingness masks, and full audit lineage (raw → quarantined → silver → gold).
from pyspark.sql import functions as F

def deidentify_clinical_df(df, salt: str):
    return (
        df.withColumn("subject_key", F.sha2(F.concat_ws("||", F.lit(salt), F.col("patient_id")), 256))
          .withColumn("clean_notes", F.regexp_replace(
              F.col("clinical_notes"),
              r"(\b\d{10}\b|[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,})",
              "[REDACTED]"
          ))
          .drop("patient_id", "patient_name", "phone", "email")
    )
